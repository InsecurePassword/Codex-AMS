# AMS intensity control

Use for non-`auto` modes. Intensity changes useful topology only, never scope, acceptance, dependencies, permissions, route suitability, validation, or completion.

- `minimal`: root plus at most one active non-root; a manager must yield/close before its descendant starts.
- `balanced` / stored `moderate`: either two direct non-manager sessions or one manager with at most three direct non-manager descendants; never mix or nest.
- `heavy`: proactively use useful managers and parallel lanes when readiness/ownership permit.
- `extreme`: dispatch every useful ready safe authorized lane while remaining cost-first.
- `auto`: smallest useful topology; do not load this file merely to choose it.

Heavy/Extreme have no fixed depth or shape ceiling. Capacity, readiness, finite allocation, one-writer ownership, safety, and coordination value govern.

Before adding a lane require an existing scope basis and acceptance, ready prerequisites, non-overlapping ownership or isolation, value greater than coordination cost, and the lowest reliable profile. Unused capacity never creates work, duplicates implementation, adds optional hardening, or reopens accepted objectives. Rush is separate and requires current-turn consent.
