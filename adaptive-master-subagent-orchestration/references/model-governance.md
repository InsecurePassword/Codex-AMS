# AMS model governance

Load only when `model_governance = true`. This controls organization, not model choice or the mandatory autonomy/recovery rules.

Keep one capable owner for each coherent task through investigation, implementation, validation, and repair. Add lanes only for ready disjoint work, a bounded specialist/reviewer, a specific blocker, or supervision that saves more than it costs.

Use the order/result fields below. Load `hierarchy-control.md` before managers or bounded peer channels, `intensity-control.md` for non-`auto`, and `zergling-rush.md` only with current-turn Rush consent. Copy applicable manager or peer addenda. Never expand authority. Distinguish requested from directly observed model/effort; mark unknowns. For Luna Low, root composes RESULT; the worker sends only its execution receipt, with no generic fields or peer synthesis.
