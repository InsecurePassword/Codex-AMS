# AMS model switching

Load only when `automatic_model_switching = true`. This sets selection/reselection heuristics, not model qualifications or failure authority.

Choose the lowest reliable model and effort by expected cost to accepted completion, including input/reasoning/output usage, coordination, retries, correction, and root integration. Use model-purpose advice only if model guidance is enabled.

Keep a capable owner and its context. Correct an actionable order or invocation problem before replacing it. Raise effort or change model when evidence shows a capability mismatch or lower expected completion cost; reduce effort for newly bounded work. A route change cannot reset exhausted attempts or bypass a safety, permission, or approval boundary. Never change the user-selected master.
