# AMS app-task lane

Implicit invocation is disabled. Invoke only from an active AMS root after a direct current-session user instruction authorizes a user-visible app task for the current bounded objective. Core AMS never loads this companion from a setting.

This companion never activates or replaces AMS. The root retains the automation boundary, graph, routing, correction, integration, acceptance, completion, and user communication. Read `references/app-task-lane.md` fully before use. If required tools or a truthful route are unavailable, return blocked; never invent identity, callback, workspace, branch, or completion evidence.
